# ИнвестСигнал MVP

Рабочий прототип аналитического контура раннего выявления инвестиционных проектов.

## Возможности

- ранжированная очередь потенциальных проектов;
- поиск и фильтрация по статусу и отрасли;
- единая карточка с доказательствами и объяснением оценки;
- экспертные решения: одобрить, наблюдать, отклонить;
- назначение ответственного;
- ручное добавление сигнала;
- CSV-экспорт одобренных карточек;
- мониторинг источников и пилотная аналитика;
- локальное сохранение изменений в браузере.

## Запуск в контейнере

```bash
docker compose up -d --build
```

Приложение будет доступно по адресу `http://localhost:4173`. Порт можно изменить:

```bash
APP_PORT=8088 docker compose up -d --build
```

Проверка состояния:

```bash
docker compose ps
curl http://localhost:4173/healthz
```

Остановка:

```bash
docker compose down
```

Все показанные организации, сигналы и метрики являются демонстрационными.
